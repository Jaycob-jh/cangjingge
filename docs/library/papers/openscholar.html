书目信息

  • 题目： Synthesizing scientific literature with retrieval-augmented language models

  • 发表日期： 2026-02-04
  • DOI： 10.1038/s41586-025-10072-4
  • 开源实现： OpenScholar GitHub

核心问题

如何让语言模型从大量科学论文中定位证据，并综合多篇文献形成可以追溯来源的回答？

方法概览

OpenScholar 将学术语料检索、候选重排序和基于证据的生成相结合，并加入自我反馈以改进最终输出。论文介绍的系统以大规模公开获取的论文语料为基础。

对藏经阁的启发

  • 文献条目应保留 DOI、作者、发表信息与稳定来源。
  • AI 问答需要返回原文依据，不应只输出没有出处的总结。
  • 大规模语料索引不是第一阶段 MVP 的必要条件。

局限与后续

本站尚未集成 OpenScholar 或 RAG；这是供未来技术选型参考的研究论文。具体结果和限制应以 Nature 原文 为准。
