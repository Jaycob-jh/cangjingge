结果怎么看

  • 表 2/图 4：第一阶段 TUG 主动 12.3±4.2 秒、假刺激 11.0±4.0 秒，未显示主动优于假刺激；MDS-UPDRS 总分组内下降也未形成随机组间优势。（PDF 第 9–10 页｜表 2，主次终点和组间比较）
  • 第三阶段 TUG 继续组 9.8±3.8 秒、停止组 12.0±5.6 秒，ANCOVA p=.016；这是自选继续与否的比较，不是随机延长疗程效应。（PDF 第 11 页｜图 4a，各阶段 TUG 分布）
  • 第三阶段 MDS-UPDRS 总分差异 p=.062；个别疑似相关退出包含自述房颤/头痛、梦境和脱发，保留与获益一起报告。（PDF 第 9–10 页｜表 2，主次终点和组间比较）

对实验设计有什么用

随机阶段检验的是整套头部加颈腹光照在既有运动训练之外的额外作用。第三阶段是否继续由本人选择，要用再次随机的延长试验验证；若要隔离经颅照射贡献，还需分开头部和身体照射。
