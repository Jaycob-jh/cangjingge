藏经阁 Cangjingge · Codex MVP v0.2 / 无自定义 GitHub Actions

产品定位：文献库、研读札记、研究专题、团队知识共建。团队主页非核心。

发布模式：Quarto 构建生成 docs/ → git commit & push → GitHub Pages 从 main /docs 发布。
仓库不包含 .github/workflows，也不要求 GitHub Actions 构建。

首先阅读：
  1. AGENTS.md
  2. CODEX_START_HERE.md
  3. DEPLOY_NO_ACTIONS.md
  4. README.md

重要文件：
  _quarto.yml               Quarto 网站配置（output-dir: docs）
  index.qmd                 知识导向首页
  library/                  文献目录及真实 OpenScholar 方法参考
  notes/                    研读札记及阅读规范
  research/                 研究专题
  people/                   PI 与其他四位成员资料页
  data/people.json          成员数据唯一事实源
  scripts/build_people.py   从 JSON 生成成员页
  scripts/build_site.py     本地执行验证与 Quarto 构建
  scripts/verify_pages.py   检查 docs/ 内部链接和资源
  docs/                     可直接部署的初始静态页面快照
  docs/.nojekyll            禁用 Pages 默认 Jekyll 构建

注意：当前环境无 Quarto CLI，尚未执行正式 Quarto 渲染。初始 docs 以 Pandoc 生成，
含文献筛选与轻量搜索，Codex 应用正式 Quarto 渲染产物替换它。

基础测试：成员生成与源文件校验通过、14 个静态 HTML 链接检查通过、JS 语法检查通过。
